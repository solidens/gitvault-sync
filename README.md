# Gitvault Sync

Плагин Obsidian: синхронизирует хранилище (vault) с приватным репозиторием GitHub. Содержимое и имена файлов шифруются на устройстве паролем, на GitHub лежит только шифртекст. Доступ к репозиторию идёт через собственное GitHub App (Device Flow), без персональных токенов. Работает на десктопе и на iPhone/iPad (`isDesktopOnly: false`, `minAppVersion` 1.8.7).

## Установка

Сборка: `npm install && npm run build` (получится `main.js`).

На каждом устройстве скопируйте `main.js`, `manifest.json`, `styles.css` в `<vault>/.obsidian/plugins/gitvault-sync/` и включите плагин в Settings → Community plugins.

- iPhone: положите эти три файла в ту же папку через приложение Файлы / iCloud (папка `.obsidian/plugins` хранилища), либо поставьте плагин через BRAT из приватного GitHub release.

## Регистрация GitHub App (один раз, владелец)

Открыть https://github.com/settings/apps/new и заполнить:

1. GitHub App name: любое уникальное имя. Homepage URL: любой.
2. Webhook: снять галочку «Active».
3. Permissions → Repository permissions → Contents: **Read and write** (Metadata: Read подставится сам).
4. Отметить **Enable Device Flow**.
5. Where can this GitHub App be installed: **Any account** (иначе другие пользователи опубликованного плагина не смогут установить App; для чисто личной сборки достаточно «Only on this account»).
6. В разделе Optional features отключить истечение user-to-server токенов (Opt-out of user-to-server token expiration).
7. Create GitHub App. Скопировать **Client ID** и **slug** (последний сегмент в `https://github.com/apps/<slug>`).
8. Вписать значения в код и пересобрать:
   - `GITHUB_CLIENT_ID` в `src/auth.ts` (сейчас `"REPLACE_WITH_CLIENT_ID"`);
   - `APP_SLUG` в `src/settings.ts` (сейчас `"REPLACE_WITH_APP_SLUG"`);
   - `npm run build`.

### Проверить при регистрации приложения

Не подтверждено по документации (docs.github.com была недоступна при разработке):

- (a) Device Flow для GitHub App работает только с `client_id`, без `client_secret`.
- (b) Опция отказа от истечения user-to-server токенов существует. Если её нет, токены живут 8 часов и плагин будет просить войти заново; сообщите об этом разработчику.

## Первое подключение

Настройки плагина → «Подключение»:

1. «1. Создать репозиторий»: откроется github.com/new, создайте приватный репозиторий (пустой).
2. «2. Разрешить доступ»: установите App на свой аккаунт, выбрав «Only select repositories» и этот репозиторий; затем в окне «Вход через GitHub» нажмите «Скопировать и открыть github.com/login/device» и подтвердите код.
3. Если репозиториев несколько, выберите нужный («Выберите репозиторий»).
4. Пустой репозиторий: «Задайте пароль» (дважды). Уже инициализированный: «Введите пароль». Переключатель «Запомнить на этом устройстве» сохраняет пароль локально (вне vault и вне репозитория).

Пароль потерян = данные в репозитории не расшифровать. Локальные файлы при этом остаются нетронутыми.

## Использование

- Синхронизация идёт автоматически: при изменении файлов и периодически, пока приложение открыто.
- Команды (палитра команд): «Синхронизировать сейчас», «Пауза/продолжить», «Показать статус».
- Статус-бар (только десктоп; клик открывает журнал событий): `↻` идёт синхронизация, `✓ HH:mm` успешно, `⏸ пауза`, `⏸ лимит GitHub до HH:mm`, `⚠ N конфликтов`, `✗ не подключено`, `✗ неверный пароль`, `✗ <ошибка>`. На мобильных статус-бара нет: ошибки показываются уведомлениями (Notice), не чаще раза в 10 минут для одного сообщения; журнал доступен командой «Показать статус».
- «Выйти» в настройках стирает токен и пароль с устройства; состояние синхронизации остаётся.

### Настройки

- Имя устройства: попадает в коммиты и в имена конфликт-копий.
- Синхронизировать настройки и плагины (по умолчанию выкл.): папка `.obsidian`; изменения применяются после перезапуска Obsidian (плагин покажет уведомление).
- Игнорировать: шаблоны путей по одному на строку, например `Attachments/**` или `*.pdf`.
- Порог массового удаления, % (по умолчанию 20): если синхронизация удалит больше этой доли файлов (и больше 10 штук), она спросит подтверждение.
- Размер репозитория показывается внизу; при 700 МБ и выше выделяется предупреждением.

### Что не синхронизируется никогда

```
.obsidian/plugins/gitvault-sync/**
.obsidian/workspace*.json
.trash/**
.git/**
```

Файлы больше 50 МБ пропускаются (один раз показывается уведомление).

### Конфликты

Если файл изменён на двух устройствах, текстовые правки в разных местах сливаются молча. Правки одного места: локальная версия сохраняется копией рядом, удалённая остаётся под прежним именем:

```
Заметка (conflict iPhone 2026-10-27 1432).md
```

Счётчик конфликтов в статусе уменьшается, когда вы удалите копию.

## Ограничения GitHub

- Не более ~500 записей в час (secondary rate limit); при достижении плагин сам делает паузу и пишет «лимит GitHub до HH:mm».
- 100 МБ на файл (плагин пропускает файлы больше 50 МБ).
- Рекомендуемый размер репозитория до ~1 ГБ; предупреждение с 700 МБ. При приближении: вынесите тяжёлые вложения в «Игнорировать» или удалите ненужные.

## Проверка перед первым использованием

Ручной e2e (Mac + iPhone, реальный приватный репозиторий). Отмечайте пункты:

- [ ] Онбординг на Mac с пустым репозиторием; на iPhone с вводом пароля; неверный пароль отклоняется.
- [ ] Правка на Mac появляется на iPhone за ≤ 10 с при открытом приложении.
- [ ] Замер: тратит ли ответ 304 на `getHead` лимит (`x-ratelimit-remaining` до/после 20 опросов). Если тратит, поднять интервал опроса до 10 с и отметить здесь.
- [ ] Первая загрузка ~1000 файлов пакетом: определить максимальный размер inline-tree запроса без ошибки, выставить размер чанка с запасом 2×.
- [ ] Скачивание tarball через `requestUrl` на iPhone (редирект на codeload) работает.
- [ ] Одновременная правка одной строки: конфликт-копия на обоих устройствах; разных строк: тихий merge.
- [ ] Принудительное закрытие Obsidian на iPhone посреди синка: следующий запуск без конфликт-копий.
- [ ] В репозитории на github.com видны только `gitvault.json` и `f/**` с нечитаемым содержимым.
